# What the Space installs. Deliberately not requirements.txt.
#
# The builder's list carries psycopg, pgvector, beautifulsoup4 and PyYAML, which
# the website has no use for. Leaving them out keeps the image smaller, but the
# real reason is that a server with no Postgres driver installed cannot grow a
# Postgres dependency by accident -- an import that reaches for one fails at
# build time here, not at three in the morning in front of a visitor.
#
# torch is not pinned here on purpose. The Dockerfile installs the CPU wheel from
# PyTorch's own index first; a pin in this file would pull the CUDA build from
# PyPI instead and add 2.5 GB of driver support to a machine with no GPU.
